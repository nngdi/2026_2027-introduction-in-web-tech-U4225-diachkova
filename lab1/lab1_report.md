4\. Управление контейнерами



**Шаг 14. Остановка контейнера**



Для просмотра контейнеров использованы команды:



```powershell

docker ps

docker ps -a

```



Для остановки контейнера выполнена команда:



```powershell

docker stop web-server

```



После остановки `docker ps` больше не показывал контейнер, а `docker ps -a` показывал его со статусом `Exited`.





**Шаг 15. Повторный запуск контейнера**



Для повторного запуска выполнена команда:



```powershell

docker start web-server

```



После этого:



```powershell

docker ps

```



снова показал контейнер со статусом `Up`.
